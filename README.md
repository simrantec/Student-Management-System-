Student Information Management System

Project Overview

The Student Information Management System is a web-based application used to store and manage student records.

Features

- Add New Student
- View Student Details
- Update Student Information
- Delete Student Records
- Manage Student Data

Technologies Used

- HTML
- CSS
- PHP
- MySQL
- GitHub

Student Details

- Student ID
- Student Name
- Email Address
- Course Name
- Phone Number

Installation Steps

1. Install XAMPP on your computer.
2. Start Apache and MySQL.
3. Create the database using phpMyAdmin.
4. Import the database.sql file.
5. Place the project folder inside the htdocs directory.
6. Open the project in your browser using localhost.

Objective

The objective of this project is to manage student information digitally and reduce manual paperwork.

Conclusion

This project provides a simple way to add, view, update, and delete student records.
